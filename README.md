# 🚌 Online Bus Pass System

An online web-based system for applying and managing bus passes digitally.

## 🌐 Live Website

https://online-bus-pass-system-1.onrender.com

## ✨ Features

- User Registration
- User Login
- User Dashboard
- Online Bus Pass Application
- Multiple Bus Pass Applications
- Pass Status Tracking
- Admin Login
- Admin Dashboard
- Approve / Reject Applications
- User Management

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- GitHub
- Render
